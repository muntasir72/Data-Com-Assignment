# Digital Signal Encoder & Decoder

A C++ project that demonstrates digital line encoding and analog-to-digital conversion, with waveform visualization using Raylib.

## Features

- Digital encoding: NRZ-L, NRZ-I, Manchester, Differential Manchester, and AMI
- Scrambling: B8ZS and HDB3
- Longest binary palindrome detection
- Analog signal sampling, quantization, and PCM encoding/decoding
- Graphical waveform display

## How to Run

### Windows

1. Download `assignment.exe` from this repository.
2. Open the file to run the program.

### Run from Source

1. Install a C++ compiler and [Raylib](https://www.raylib.com/).
2. Make sure Raylib is configured for your compiler.
3. Compile `main.cpp` and link it with Raylib.
4. Run the generated executable.

When the program starts, choose **Digital Input**, **Analog Input**, or **Exit** from the menu.
